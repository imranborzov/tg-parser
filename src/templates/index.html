Getting your n8n Webhook URL

1. Open n8n and create a new workflow

2. Add a Webhook node as the trigger

3. Set the HTTP method to POST

4. Copy the Webhook URL shown in the node — paste it here

5. Use the Test button to verify it works

Creating a bot with @BotFather

1. Open @BotFather in Telegram

2. Send /newbot

3. Choose a name and username for your bot

4. Copy the token BotFather gives you — looks like 1234567890:AAH...

Finding your Chat ID

Personal chat: message @userinfobot — it replies with your ID

Group or channel: add your bot to the chat, then forward any message to @userinfobot — copy the chat ID from the reply

Group IDs start with -100...

    Manage Keywords

    How keywords work

    • Matching is case-insensitive — "Bitcoin" catches "bitcoin", "BITCOIN", "BiTcOiN"

    • Use phrases for precision — "buy btc" won't trigger on "sell btc"

    • Shorter keywords match more broadly, longer ones are more precise

    • Separate multiple keywords with commas to add them all at once
